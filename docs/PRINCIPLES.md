# Product principles

1. **Zero manual memory** — routine continuity should be automatic.
2. **Every AI action is traceable** — source, agent, time and evidence matter.
3. **Facts beat claims** — Git/files/tests/runtime outrank model summaries.
4. **Retrieve context, do not dump repositories** — spend tokens only on relevant evidence.
5. **Repair must be verified and reversible** — no "the AI said it works".
6. **Local-first** — code and raw sessions stay local unless the user opts into sync.
7. **Vendor-neutral** — no AI provider becomes the canonical source of project truth.
8. **Failed work is valuable memory** — do not repeat proven dead ends.
9. **Stale memory is unsafe memory** — invalidate or reconcile when evidence changes.
10. **Adapters are replaceable; the project graph is durable.**
