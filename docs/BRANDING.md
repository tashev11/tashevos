# TashevOS brand assets

This directory contains repository-safe brand assets for documentation, releases and community use.

## Assets

| File | Purpose |
|---|---|
| `tashevos-hero.svg` | Main README hero |
| `tashevos-mark.svg` | Square TashevOS mark |
| `tashevos-mark.png` | Raster mark for services that do not accept SVG |
| `architecture.svg` | Product architecture diagram |
| `lifecycle.svg` | Task lifecycle diagram |
| `terminal-demo.svg` | Documentation terminal illustration |
| `social-preview.svg` | Editable social preview source |
| `social-preview.png` | 1280×640 social preview ready for GitHub/social sharing |

## Core message

**TashevOS — One project. Every AI. Zero lost context.**

Supporting description:

> The open control plane for multi-agent AI coding.

## Visual language

- dark infrastructure background;
- cyan for context/connectivity;
- violet for memory/intelligence;
- green for verified health/safety;
- network nodes represent multiple AI tools connected through one project truth layer.
