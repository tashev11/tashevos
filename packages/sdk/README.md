# TashevOS Adapter SDK

The adapter SDK will be licensed under Apache-2.0 so AI vendors, IDEs and community projects can integrate TashevOS without inheriting the AGPL license of the core.

Planned adapter capabilities:
- client detection;
- instruction/rules installation;
- lifecycle hooks;
- session/history import;
- MCP/ACP capability registration;
- health checks;
- safe uninstall/restore.

The SDK API is intentionally not frozen in v0.1.
