# Code of Conduct

We want TashevOS to be a productive, technically rigorous and welcoming project.

Participants should discuss ideas and code without harassment, personal attacks, discrimination or deliberate disruption. Critique technical decisions directly and respectfully. Assume good faith while requiring evidence for technical claims.

Maintainers may remove abusive content or restrict participation when necessary to protect the project and its contributors.

For sensitive conduct reports, contact maintainers privately rather than posting personal details publicly.
