## Long version

# TashevOS: TashevOS v0.1.0-alpha.1 — Foundation

First public TashevOS alpha.

Included:
- project and Git discovery;
- AI detection for Claude Code, Codex, Cursor, Gemini CLI, Copilot, Windsurf, Kiro, Cline, Roo, OpenCode, Continue, Qwen, Zed and Aider markers;
- local event memory primitives;
- AGENTS/CLAUDE/GEMINI managed bootstrap;
- compact evidence-first context packets;
- doctor and safe-heal primitives;
- public architecture, memory, auto-healing and 30+ AI compatibility roadmap;
- Apache-licensed adapter SDK contract skeleton.

This is a foundation release, not yet a production-stable API.
